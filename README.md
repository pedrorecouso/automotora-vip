# 🚗 Automotora VIP

Sitio web frontend para una concesionaria de vehículos, desarrollado como proyecto práctico para aplicar maquetación responsive, consumo de APIs y renderizado dinámico en el navegador.

## 🌐 Demo en vivo

Podés probar el sitio funcionando online acá: **[Automotora VIP - GitHub Pages](https://pedrorecouso.github.io/automotora-vip/)**

## ✨ Funcionalidades principales

- **Catálogo dinámico (`ventas.html`):** Carga de vehículos, marcas y cotización de moneda mediante peticiones asíncronas (`fetch` / AJAX) y renderizado reactivo con **Vue.js**.
- **Filtros dependientes:** Búsqueda y filtrado de autos por marca, modelo, año y estado, actualizando la vista en tiempo real.
- **Modo oscuro / claro:** Cambio de tema persistente en toda la interfaz (`theme.js`) adaptado a componentes, tarjetas, formularios y navegación.
- **Secciones institucionales:** Página principal (`index.html`), sección corporativa con contadores animados e información del equipo (`sobre-nosotros.html`), y modal/formulario de contacto con filtros de consulta.
- **Animaciones y diseño responsive:** Interfaz adaptada a dispositivos móviles y escritorio utilizando **Bootstrap 5.3** y animaciones al hacer scroll con **AOS**.

## 🛠️ Tecnologías utilizadas

- **HTML5** y **CSS3** (variables CSS y estilos personalizados para temas claro/oscuro)
- **JavaScript (ES6+)**
- **Vue.js**
- **Bootstrap 5.3**
- **AOS (Animate On Scroll)**
